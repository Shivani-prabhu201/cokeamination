COKEAMINATION - scroll-through animated website
Open index.html in a browser (double-click) or host the whole folder on any web server.

cokeamination/
  index.html      page markup
  css/style.css   all styles (responsive: 4K, desktop, laptop, tablet, mobile, landscape phones)
  js/main.js      scroll animation, glass navbar, filters, cart, gallery viewer, contact form
  images/         logo and photos
  frames/         240 animation frames (frame-001.jpg ... frame-240.jpg) - to upgrade quality,
                  replace with higher-resolution frames using the same names
